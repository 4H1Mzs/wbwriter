Built for the show

One pen. One button. Nothing else on stage.

Everything is set before the show. In live mode the performer gets a board and an eraser, and the video desk gets a clean signal.

Clean NDI® feed
Only the inside of the board is sent, with no UI and no border. Name the source yourself and pick a frame rate. NDI 6.3 · 23.976–60 fps
Black or transparent
Send a black background, or alpha for keying the writing over graphics. BGRX · BGRA straight alpha
Your LED wall's resolution
Enter the wall's exact pixels. The board is scaled to fit the touchscreen with the aspect ratio locked, so what the performer sees is what goes out. 1920×1080 · 3840×2160 · custom
HDMI program out
Run a full-screen clean feed on any external display, alongside NDI or instead of it.
Hatched no-draw zone
The area around the board is hatched, so nobody writes where the camera can't see. The board also stays clear of the MacBook notch.
Clear button you choose
A large eraser in the corner you pick. Single tap, double tap for safety, or no button at all.
Status line for the operator
A small readout beside the board shows whether NDI is healthy, the measured fps, receivers, network load and battery. It never reaches the output.
Web control from a phone
Turn it on, and the video desk can clear the board or show the performer a message in the hatched area, from any phone on the network. It never reaches the output, and a PIN can protect it.
Updates built in
At launch, WBWriter offers new versions with their changelog. Updates install in one click, and only when they're signed by 4H1M.
Show-safe
Dock and menu bar are hidden, sleep is off, and the setup stays locked while live. Esc goes back to setup.

How it works

Set it up once, then just write.

  1. Set up before the show

    Resolution, frame rate, NDI name, background, pen color and width, where the clear button sits, and which screen is the touchscreen.

  2. Go live

    The board takes over the touchscreen. Receivers see the source as MACHINE (WBWriter).

  3. Write

    White marker on black by default, the same thickness as OpenBoard's strongest pen. Smooth, round strokes at full output resolution.

  4. Clear and repeat

    Tap the eraser between messages. Press Esc when the show is over.

WBWriter is open source under the MIT License. Read the code, check how the NDI output works, build your own copy, or change it for your show. Bug reports, ideas and pull requests are welcome.

  • MIT licensed. Use it, change it and share it, in any production, commercial or not.
  • Native and small. Swift and AppKit, with no web runtime inside.

  • Signed releases from CI. Every tagged version is built, signed and notarized automatically.
